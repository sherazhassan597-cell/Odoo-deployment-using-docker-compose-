# Odoo-deployment-using-docker-compose

##  Why Docker Compose?

Docker Compose allows multiple services to run as a unified application stack.  
Using a single command:

docker compose up -d

all containers start together.  
Similarly, the entire stack can be stopped using:

docker compose down -v

This simplifies management of multi-container applications like Odoo and PostgreSQL.
